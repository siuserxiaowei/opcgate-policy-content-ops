# OPC Gate 空间匹配与申请助手

> 告诉 OPC Gate 你在哪里、做什么、需要什么，它会推荐适合的 OPC 空间，解释匹配依据，并帮你准备下一步申请。

OPC Gate 面向正在寻找落地空间的一人公司、独立开发者和小型创业团队，同时帮助园区招商与创业服务运营完成重复咨询、需求分流和线索预筛。

## 解决什么问题

创业者通常能找到很多园区介绍和政策文章，却仍然不知道：

- 哪些空间与自己的城市、行业和阶段真正相关；
- 哪个空间能提供工位、算力、融资、注册或跨境服务；
- 推荐依据来自哪里，信息是否经过核验；
- 下一步有无公开入口，需要准备什么材料。

园区运营则要反复回答相似问题，再人工判断应该把咨询分流给哪个载体。

## 核心流程

1. 选择目标城市、行业、项目阶段和所需服务；
2. 从 128 个 OPC 载体样本中生成可解释排序；
3. 每张“空间匹配护照”展示地址、运营方、服务特征、推荐理由和证据状态；
4. 选择 2–3 个候选做横向比较；
5. 按项目阶段生成申请材料清单；
6. 只有资料明确写出的公开线上入口才会展示为入口，其余情况提示联系运营方核验。

推荐分数只用于本次信息筛选，**不代表入驻资格、获批概率或政府推荐**。

## 数据口径

- 128 个 OPC 社区 / 载体样本；
- 载体覆盖 38 个城市；
- 119 个样本含地址，126 个关联政策；
- 53 个样本含已核验介绍来源；
- 125 条公开政策作为推荐解释的辅助证据；
- 数据快照日期：2026-05-22。

当前数据质量并不均匀。缺少可靠来源的载体会明确显示“信息待核验”，不会生成虚假申请入口。

## 本地运行

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python app.py
```

部署配置：Gradio 6.17.3、入口 `app.py`、免费 CPU，无需 API Token 即可完成核心流程。

## 验证

```bash
python3 -m unittest discover -s tests -p 'test_*.py' -v
npm test
```

Python 新版核心测试覆盖：城市 / 行业 / 阶段 / 服务需求排序、证据字段、公开入口提取、无来源边界、2–3 项比较、分阶段申请清单、空输入和 UI 输出。核心 `app.py` 覆盖率为 82%。既有 JavaScript 回归测试继续保留。

## 已知限制

- 当前是基于公开数据快照的可解释匹配，不是实时招商系统；
- 载体权益、空置状态和申请要求可能变化，应向运营方再次确认；
- 来源页面不等于申请页面；只有明确标注的公开入口才作为入口展示；
- 推荐不代表入驻资格，最终决定权属于载体运营方；
- 当前没有真实用户量、转化率或节省时长数据，不作相关宣称。
