## 作品表单

### 作品名称

OPC Gate 政策内容运营助手

### 一句话介绍

把公开话题转成有来源、有边界、发布前可核验的政策内容。

### 运营问题

政策类内容需要同时处理来源、时效、适用对象、城市差异和表达风险。运营人员要在多份政策原文与载体信息之间反复检索、复制和核验；通用生成式 AI 又容易把内容相关性写成资格结论，造成返工和合规风险。

### 解决方案

系统先通过确定性规则从 125 条政策、42 个城市 / 适用范围和 128 个载体样本中整理证据，展示来源、数据日期、命中理由与适用边界，再按“事实 / 推断 / 待核验”生成草稿。ModelScope API-Inference 可在证据范围内改写，模型异常或 Token 缺失时自动退回规则草稿。最后由人工核验门禁提醒发布者回到官方原文逐项检查。

### 核心功能

1. 手动输入公开话题或非实时演示场景；
2. 关键词与运营意图提取；
3. 可解释政策相关性匹配；
4. 来源、日期、原文链接与适用边界展示；
5. “事实 / 推断 / 待核验”三层草稿；
6. ModelScope API-Inference 可选改写；
7. 模型输出二次确定性扫描；
8. 无 Token / 模型异常安全降级；
9. 发布前人工核验门禁。

### 技术实现

Gradio 6.17.3 部署在 ModelScope 创空间；Python 标准库实现可解释规则、公共 URL 校验和输出风险扫描；ModelScope API-Inference 使用 OpenAI 兼容接口，默认模型为 `Qwen/Qwen3.5-35B-A3B`，以平台支持情况为准。代码与密钥分离，未配置 Token 时核心流程仍可运行。

### 预期效果

把原本分散的“找选题—查政策—找原文—写草稿—检查风险”收进一个可运行工作台。现阶段不虚构节省时长或转化率；上线后使用真实运营任务记录完成时间、页面与复制次数、发现的事实问题和草稿返工次数。
