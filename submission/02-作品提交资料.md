# 作品提交资料

## 作品名称

OPC Gate 政策内容运营助手

## 一句话介绍

把公开话题转成有来源、有边界、发布前可核验的政策内容。

## 作品方向

AI + 运营 / 内容工厂 / 园区与创业服务内容运营

## 目标用户

- 产业园区和孵化器内容运营；
- 创业服务机构和城市招商内容团队；
- 政策研究、新媒体和独立内容创作者；
- 需要解读 OPC、一人公司与 AI 创业政策的运营人员。

## 运营问题

政策类内容需要同时处理时效、来源、适用对象、城市差异和表达风险。运营人员要在多份政策原文和载体信息之间反复检索、复制和核验；通用生成式 AI 又容易把相关性写成资格结论，造成返工和合规风险。

## 解决方案

系统先通过确定性规则从完整数据快照中整理证据，再按“事实 / 推断 / 待核验”生成草稿；可选调用 ModelScope API-Inference 做受限改写，返回后再次经过规则扫描。模型异常或 Token 缺失时，规则分析和草稿仍可运行。最后通过人工核验清单提醒运营回到政策原文检查。

## 核心功能

1. 手动输入公开话题或非实时演示场景；
2. 关键词与运营意图提取；
3. 125 条政策相关性匹配；
4. 城市 / 适用范围与 128 个载体线索聚合；
5. 来源类型、数据日期、匹配理由与适用边界展示；
6. 三层政策内容草稿；
7. ModelScope API-Inference 可选改写；
8. AI 输出后二次风险扫描和自动降级；
9. 发布前人工核验门禁。

## 技术实现

- 前端 / 应用：Gradio 4.44.1；
- 部署：ModelScope 创空间，免费 CPU；
- AI：ModelScope API-Inference OpenAI 兼容接口；
- 默认模型：`Qwen/Qwen3.5-35B-A3B`，以平台支持列表为准；
- 核心分析：Python 标准库可解释规则；
- 数据：OPC Gate 公开数据快照；
- 安全：输入长度限制、公共 URL 校验、模型证据约束、确定性后扫、无 Token 降级。

## 数据口径

- 125 条政策记录；
- 42 个城市 / 适用范围；
- 128 个社区 / 载体样本；
- 数据快照：2026-05-22；
- 相关性排序不等于资格判断、获批概率或政府推荐。
