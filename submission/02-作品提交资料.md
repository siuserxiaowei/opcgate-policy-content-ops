# 作品提交资料

## 作品名称

OPC Gate 空间匹配与申请助手

## 一句话介绍

根据城市、行业、项目阶段和服务需求，推荐适合的 OPC 空间，解释匹配依据，并帮助比较和准备申请。

## 作品方向

AI + 运营 / 园区招商运营 / 创业服务需求分流

## 目标用户

- 正在寻找落地空间的一人公司、独立开发者和小型创业团队；
- OPC 社区、孵化器和产业园区招商运营；
- 为创业者提供注册、政策、融资和空间服务的机构。

## 运营问题

载体介绍、政策权益和申请方式分散在不同页面。创业者不知道该选哪个空间，园区运营又要反复回答“我适不适合、你们有什么服务、下一步怎么申请”，再人工完成需求分流和线索预筛。

## 解决方案

系统将用户的城市作为同城硬筛选，再用行业、阶段、服务需求和项目描述进行可解释排序。每个结果以“空间匹配护照”展示推荐原因、地址、运营方、服务特征、证据状态和申请入口状态。用户可选择 2–3 个候选比较，并获得分阶段申请材料清单。

## 核心功能

1. 城市、行业、项目阶段和服务需求画像；
2. 128 个 OPC 载体的可解释排序；
3. 空间匹配护照；
4. 来源完整度和待核验状态；
5. 只有明确公开入口才展示跳转；
6. 2–3 个空间横向比较；
7. 按“只有想法 / 已有 Demo / 已有客户 / 已注册企业”生成申请材料清单；
8. 空条件、无结果和过期比较项的安全处理；
9. 桌面和手机响应式体验。

## 技术实现

- Python 可解释规则：城市硬筛选，行业 / 服务 / 阶段加权排序；
- Gradio 6.17.3：ModelScope 创空间交互界面；
- 标准库 URL 安全检查和显式入口提取；
- 128 个载体、125 条政策的公开数据快照；
- Python 单元 / 集成测试与浏览器端完整流程验收。

## 数据边界

- 载体覆盖 38 个城市；
- 53 个载体有已核验介绍来源，其余结果明确标记待核验；
- 来源页不自动视为申请页；
- 推荐分数不代表入驻资格、获批概率或政府推荐；
- 载体权益与入口可能变化，需向运营方再次确认。
